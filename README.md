# Рекомендательная система постов для соцсети
## 🎓 Финальный проект курса ["Инженер машинного обучения"](https://karpov.courses/ml-start) в школе karpov.courses

## 📌 Описание проекта

Разработан сервис персонализированных рекомендаций постов для пользователей социальной сети студентов karpov.courses. Цель — заменить случайную выдачу постов на умную ленту, учитывающую профиль, активность и содержание постов.

## 🧠 Реализованные модели

В проекте реализованы две модели:

1. **CatBoost + TF-IDF**
   - Используются фичи пользователя и признаки постов, извлечённые через TF-IDF.

2. **CatBoost + BERT**
   - Вместо TF-IDF используются эмбеддинги, полученные с помощью `bert-base-cased`.

Обе модели обучаются оффлайн, а затем используются в продакшене без дообучения.

## ⚙️ Архитектура пайплайна

1. **Загрузка и анализ данных** из PostgreSQL.
2. **Генерация признаков**: пользовательские, поведенческие, текстовые.
3. **Формирование обучающей выборки**.
4. **Обучение и валидация модели** (CatBoost).
5. **Сохранение модели**.
6. **FastAPI-сервис** для получения топ-5 релевантных постов для каждого пользователя.

## 🧪 Метрика

Оценка производится по метрике **hitrate@5** — модель должна предсказать хотя бы 1 правильный пост в топ-5.
